# 🏔️ CaveStorage — Пещера Хранителя

**CaveStorage** — Java-проект с реализацией системы управления складскими запасами с ограниченной вместимостью.

---

## 📋 О проекте

Консольное приложение в жанре RPG-лоров, моделирующее древнее хранилище провианта в скалистых горах Альтерии. Первые поселенцы вырезали тайное хранилище в глубине гор, чтобы спасать запасы от долгих зим и вражеских набегов.

### Классы приложения

| Класс | Назначение |
|-------|------------|
| **CaveMain** | Точка входа: демонстрирует работу хранилища в интерактивном режиме |
| **CaveStorage** | Основной класс хранилища с ограниченной вместимостью (150 единиц) |
| **Provision** | Модель провианта: название, описание, количество, питательность |
| **ProvisionNotFoundException** | Исключение — провиант с указанным именем не найден |
| **InsufficientProvisionException** | Исключение — запрошено больше, чем доступно |

### Функционал

- **Добавление провианта** — кладём запасы в хранилище. Если такой провиант уже есть — количество суммируется
- **Получение провианта** — забираем нужное количество. При полном расходе позиция удаляется
- **Проверка наличия** — регистронезависимый поиск по имени
- **Контроль вместимости** — нельзя добавить больше, чем позволяет capacity (150 единиц)
- **Инвентаризация** — вывод всех запасов с питательной ценностью

### Обработка ошибок

| Ситуация | Исключение |
|----------|------------|
| Превышена общая вместимость или оставшееся место | `IllegalStateException` |
| Запрос несуществующего провианта | `ProvisionNotFoundException` |
| Запрошено больше единиц, чем есть в наличии | `InsufficientProvisionException` |

## 🧪 Тестирование

Проект покрыт **unit-тестами** (JUnit 5) с проверкой **100% строк, ветвлений и методов** класса `CaveStorage`.

### Стек тестирования

| Инструмент | Назначение |
|------------|------------|
| JUnit 5 | Написание тестов |
| JaCoCo | Измерение покрытия кода |

### Покрытые сценарии

| Категория | Сценарии |
|-----------|----------|
| **Конструктор** | Инициализация полей, начальная загрузка |
| **hasSpace()** | Пустое хранилище, почти полное, граничное значение (150), превышение (151), с учётом загрузки |
| **addProvision()** | Добавление в пустое, объединение дубликатов, превышение ёмкости, превышение остатка, заполнение ровно до предела |
| **hasProvision()** | Существующий, отсутствующий, регистронезависимость |
| **getQuantity()** | Существующий, отсутствующий (0) |
| **getProvision()** | Уменьшение количества, полный расход, регистронезависимость |
| **Исключения** | `ProvisionNotFoundException`, `InsufficientProvisionException`, `IllegalStateException` — с проверкой сообщений |
| **showInventory()** | Пустое хранилище, заполненное — с проверкой содержимого вывода |

### Запуск тестов

```bash
./gradlew test                          # запустить тесты
./gradlew jacocoTestReport              # сгенерировать HTML-отчёт
./gradlew jacocoTestCoverageVerification # проверить 100% покрытия
```

HTML-отчёт JaCoCo: `build/reports/jacoco/test/html/index.html`
